How it works

Wet soil conducts electricity, dry soil hardly does. The Pi turns that into a yes or no with a voltage divider and one digital input. No extra chip needed.

  1. Pulse

    GPIO 4 goes HIGH for 10 ms and powers the divider. The rest of the time the probes get no current, which slows corrosion.

  2. Read

    GPIO 17 reads the node between the resistors and the soil. Wet soil pulls it down to LOW. Dry soil lets it stay HIGH.

  3. React

    Dry: the LED lights up and the console prints “Dry”. Wet: the LED stays off. Then the Pi waits two seconds.

Then it starts again at step 1, until you press Ctrl+C.

Why these resistors?

Rtop = 3 × 330 Ω + 2 × 10 kΩ ≈ 21 kΩ

The chain is the upper half of a voltage divider and the soil is the lower half. The Pi’s internal pull-down (about 50 kΩ) sits in parallel with the soil. GPIO 17 flips from LOW to HIGH when the soil is around 36 kΩ.

The switching point of a real input varies a little from Pi to Pi, so treat 36 kΩ as an estimate.

Check the LED direction first if nothing lights up. The long leg points toward the resistor and GPIO 27. Always keep the 330 Ω resistor in the LED branch, or the LED draws too much current from the pin.

Run it

Do this on the Raspberry Pi. On Windows or macOS you can edit the script, but the GPIO library only runs on a Pi. Use the simulator above to try the logic anywhere.

  1. Open a terminal

    Press Ctrl+Alt+T, or use the menu under Accessories.

  2. Install the GPIO library

    Raspberry Pi OS usually has it already. On a Pi 5 install python3-rpi-lgpio instead, it is a drop-in replacement.

    sudo apt update
sudo apt install python3-rpi.gpio

  3. Get the code

    git clone https://github.com/Nathanyiel/Raspberry-Pi_Moisture_Sensor.git
cd Raspberry-Pi_Moisture_Sensor

  4. Start the sensor

    Push the probes into the soil. Press Ctrl+C to stop.

    python3 feuchtigkeits_sensor.py

The code, piece by piece

The whole script is about 30 lines. Pick a part to see what it does. Comments are trimmed here.

import RPi.GPIO as GPIO
import time
 
GPIO.setmode(GPIO.BCM)
 
GPIO_OUT = 4    # supplies the divider briefly
GPIO_IN  = 17   # reads the measuring node
GPIO_LED = 27   # LED
 
GPIO.setup(GPIO_OUT, GPIO.OUT, initial=GPIO.LOW)
GPIO.setup(GPIO_IN, GPIO.IN, pull_up_down=GPIO.PUD_DOWN)
GPIO.setup(GPIO_LED, GPIO.OUT, initial=GPIO.LOW)
 
def measure_once(pulse_ms=10):
    GPIO.output(GPIO_OUT, GPIO.HIGH)
    time.sleep(pulse_ms/1000.0)
    val = GPIO.input(GPIO_IN)
    GPIO.output(GPIO_OUT, GPIO.LOW)
    return val
 
try:
    while True:
        v = measure_once(10)
        if v == 0:
            GPIO.output(GPIO_LED, GPIO.LOW)
            print("Wet (GPIO_IN LOW)")
        else:
            GPIO.output(GPIO_LED, GPIO.HIGH)
            print("Dry (GPIO_IN HIGH)")
        time.sleep(2.0)
finally:
    GPIO.cleanup()

Pins

The script uses BCM numbering, so these are GPIO numbers and not the physical pin numbers. GPIO 4 sends the supply pulse, GPIO 17 reads the measuring node and GPIO 27 drives the LED.

Setup

GPIO 4 and 27 are outputs and start LOW. GPIO 17 is an input with an internal pull-down, so it reads LOW unless the divider pushes it high.

One measurement

Switch the divider on, wait 10 ms, read GPIO 17, switch the divider off. The function returns 0 for LOW (wet) or 1 for HIGH (dry). Keeping the current on for only a moment slows down corrosion on the probes.

Main loop

Measure, then react: LOW means wet, so the LED goes off. HIGH means dry, so the LED goes on as a warning. Both cases print a line. The Pi waits two seconds and repeats. Ctrl+C ends the loop and GPIO.cleanup() resets the pins.

Take it further

The project is small on purpose. Here are some next steps if you want to build on it.

  • Log the readingsWrite a timestamp and the reading to a CSV file and plot how fast your plant dries out.
  • Get a messageSend a push message or email when the soil has been dry for a few readings in a row.
  • Measure real valuesAdd an analog-to-digital converter such as the MCP3008 to get a percentage instead of wet or dry.
  • Water automaticallyDrive a small pump through a relay or transistor when the soil is dry.
  • Start on bootRun the script as a systemd service so it keeps watching after a reboot.
  • Watch several plantsRepeat the divider on more GPIO pins and loop over a list of sensors.
